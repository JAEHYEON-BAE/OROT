# OROT

국내 바이닐의 발매 일정과 예약판매 소식을 한곳에서 확인하고, 알림으로 받아보는 서비스입니다.
계정 없이 웹에서 일정을 살펴보거나 푸시·캘린더·RSS를 구독할 수 있습니다.

[OROT 이용하기](https://jaehyeonui-macmini.tail598a5f.ts.net)

## 일정 살펴보기

- **피드**에서 발매·예약 일정을 발매 임박순 또는 최근 변경순으로 확인합니다.
- **캘린더**에서 한 달의 일정을 모아봅니다.
- 음반을 선택하면 예약 시작·마감, 발매일, 구매처 등 등록된 정보를 확인할 수 있습니다.
  구매처 링크를 누르면 해당 판매 사이트로 이동합니다.

## 알림과 구독

서비스의 **구독** 페이지에서 원하는 방식을 선택하세요.

### 푸시 알림

**알림 켜기**를 누르고 브라우저의 알림 권한을 허용하세요.
새 일정과 일정 변경, 예약 시작 24시간 전·예약 시작·발매 알림을 받을 수 있습니다.
알림은 기기별로 설정하며, 같은 페이지의 **알림 끄기**로 해제할 수 있습니다.

아이폰에서는 Safari의 공유 메뉴에서 **홈 화면에 추가**한 뒤, 추가된 아이콘으로
OROT을 열어 설정하세요. 알림이 차단되어 있다면 브라우저의 사이트 설정에서 알림을 허용해주세요.

### 캘린더 구독

구독 페이지의 **iCalendar 주소**를 복사해 사용하는 캘린더 앱의 URL 구독 기능에 추가하세요.
예약 시작과 발매 일정을 내 캘린더에서 확인할 수 있습니다.
캘린더 앱의 갱신 주기에 따라 일정 변경이 반영되기까지 시간이 걸릴 수 있습니다.

### RSS 구독

구독 페이지의 **RSS 주소**를 복사해 RSS 리더에 추가하세요.
리더에서 새 일정과 변경 소식을 모아볼 수 있습니다.

## 이용 안내

현재는 운영자가 등록한 일정을 제공합니다.
일정과 판매 정보는 변경될 수 있으므로, 구매 전 판매처의 최신 안내를 확인해주세요.
