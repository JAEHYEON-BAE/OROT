# ADR-0008: T-116 운영자 장애 알림 채널

- 상태: Draft — 2026-09-11
- 범위: T-116의 재시도 소진·스케줄러 오류를 운영자에게 전달하는 경로

## 현재 상태

배송은 최대 3회 시도하며 404/410 구독을 비활성화한다. 재시도 소진과 스케줄러
예외는 로그로만 남는다. 운영자가 로그를 보지 않으면 장애를 알 수 없다.

## 제안

운영자가 지정한 HTTPS 웹훅을 별도 장애 알림 채널로 둔다. 일반 구독자에게 장애
알림을 보내지 않는다. 수신 URL은 환경 변수로만 설정하고 코드·로그에는 노출하지 않는다.
재시도 소진은 DB의 실패 기록을 기반으로 감지하고 중복 발송을 제한한다.
알림 전송 실패가 정상 배송 트랜잭션을 롤백시키지 않게 분리한다.
스케줄러/DB 오류는 DB 기록에 의존하지 않는 경로로도 알린다.

기본안은 Discord/Slack 등 운영자가 관리하는 웹훅이다. 구독자용 Web Push의 키나
발송 서비스 장애와 독립적으로 알릴 수 있다. 구체적인 수신 채널과 활성화 설정은
운영자의 선택이 필요하다. 실제 시험 메시지는 별도 승인 없이 전송하지 않는다.

## 대안

- 운영자용 Web Push 구독을 별도로 지정: 별도 서비스 없이 이용 가능하지만
  일반 알림과 전송 인프라가 같아 VAPID/푸시 서비스 장애 때 함께 실패할 수 있다.
- 관리자 화면 경고만 표시: 외부 설정은 없지만 화면을 열지 않으면 알 수 없어
  현재 T-116의 외부 장애 알림 완료 조건을 충족하지 않는다.

## 검증

실제 네트워크 대신 가짜 발송기와 HTTP transport로 의도적 실패, 재시도 제한,
404/410 비활성화, 장애 알림 중복 제한, 장애 알림 실패 시 정상 배송 보존을 검증한다.

## 채널 결정 전 검증 결과 — 2026-09-11

- make lint 통과, make test: 398 passed / 기존 2 xfailed.
- 격리 DB 9개 시나리오 통과. 최대 3회 재시도 소진 및 한 발송기의 예외 후 다른 배송 계속 처리 포함.
- 가짜 HTTP 발송으로 404/410은 GONE, 429/500/503은 FAILED 분류 확인.
- 기존 데이터 변경이나 실제 시험 알림은 없음. 운영자 외부 알림은 아직 구현하지 않았으며 수신 채널 선택 대기 중.
