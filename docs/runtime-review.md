# 실행 흐름·버그 점검 — 2026-09-10

현재 수동 등록 경로를 기준으로 API·DB·스케줄러·Web Push·웹·백업을 점검했다.
자동 수집기는 아직 스케줄러에 연결하지 않았다. 기존 작업 중 변경 사항은 유지했다.

## 실행 흐름

1. 운영자가 로컬 API의 관리자 화면에서 초안을 등록한다.
2. 공개 시 `SCHEDULE_ADDED` 이벤트를 만들고 공개 API와 피드·캘린더에 노출한다.
3. collector가 60초마다 예약 임박·예약 시작·발매 이벤트를 생성한다.
4. 이벤트 이후부터 구독한 활성 기기에 배송을 계획한다. 최대 48시간 이내 이벤트만 대상이다.
5. 발송기는 Web Push 서비스를 호출하고 배송 결과를 저장한다. 브라우저 서비스워커가 알림을 표시한다.
6. Funnel은 웹의 3000번 포트만 공개한다. 웹은 내부 API를 조회하며 푸시·RSS·ICS 경로를 중계한다.

## 수정한 문제

| 경로 | 문제와 변경 |
| --- | --- |
| 알림 실패 | FAILED가 재처리되지 않던 경로에 최대 3회 시도와 재시도 대기 조건 추가 |
| 대기 중 알림 | 공개 취소·구독 해지·이벤트 무효화·기한 초과를 전송 직전 다시 확인 |
| 발송 예외 | 한 건의 발송기 예외가 앞서 성공한 모든 배송의 DB 기록을 롤백시키던 문제 완화 |
| 동시 실행 | collector 프로세스 간 DB 잠금, 배송 행 잠금, 관리자 변경 행 잠금 적용 |
| 일정 변경 | 비공개 상태에서 수정한 과거 공개 일정도 옛 이벤트를 무효화 |
| 날짜·시각 | 발매일을 KST 자정으로 판단, 새 이벤트의 발생 시각을 검사 시각과 일치시켜 같은 주기에 발송 계획 |
| 운영자 저장 | 일정·구매처를 단일 PATCH 트랜잭션으로 저장, 중복 제출 차단, 동시 아티스트 생성 충돌 처리 |
| 삭제 가능 표시 | 연결된 수집 상품이 있는 경우 실제 삭제 제한과 화면의 `can_delete`를 일치시킴 |
| API 성공 응답 | DB 커밋을 응답 전으로 이동. FastAPI 최소 버전을 해당 기능을 지원하는 0.121로 조정 |
| 입력 경계 | null/공백 제목, null 한정반 여부, 잘못된 URL·가격·페이지 커서 거부 |
| 구독 | 동시 구독 등록/재활성화 정원 검사 직렬화, 재활성화 이전 이벤트 발송 제외 |
| Safari·서비스워커 | 권한 요청을 네트워크 대기 전에 실행, 등록 실패 시 새 브라우저 구독 정리, 해지 실패를 성공으로 표시하지 않음 |
| 구독 교체·클릭 | 새 엔드포인트 등록 실패 시 기존 서버 구독 유지, 잘못된 알림 URL에 홈 화면 폴백 |
| 캘린더 | UTC 서버에서 이전 달을 표시하던 문제, 100건 이후 누락, 중복 month 쿼리 오류 수정 |
| ICS | 분 단위 덧셈으로 일정 길이가 0분이 되던 문제를 30분 timedelta로 수정 |
| 공개 구독 주소 | Funnel 도메인에 RSS·ICS 중계 추가, 실행 시 공개 URL 사용, 내부/localhost 링크 수정 |
| 웹 응답 | API 조회 제한 시간 추가, 0원 가격 표시, 가격 응답 타입 정합성 수정 |
| 본문 제한 | ASGI 수신 함수가 동일 본문을 무한 재전달할 수 있던 경로 수정 |
| 백업·복구 | macOS make에서도 pg_dump 실패 감지. 압축 해제 성공 후 단일 트랜잭션으로 복구하고 SQL 오류 시 중단 |
| 이미지 빌드 | 백업 파일과 브라우저 테스트 산출물을 Docker 빌드 컨텍스트에서 제외 |

## 검증

- `make lint`: Ruff·포맷·core mypy 통과.
- `make test`: 393 passed, 기존 2 xfailed.
- 웹 ESLint, Node 회귀 테스트 19개 통과.
- 로컬 webpack 빌드와 서비스 Docker 빌드 통과.
- `make openapi`로 API 스냅샷 갱신.
- `apps/api/tests/integration_runtime.py`: 별도 PostgreSQL 스키마에서 재시도/멱등성,
  만료 구독, 관리자 CRUD/비공개 일정 변경/원자적 링크 저장,
  KST/ICS/동일 주기 배송 계획, 공개 취소·구독 해지·이벤트 무효화 7개 시나리오 통과.
  가짜 발송기만 사용했고 바깥 트랜잭션 롤백 후 임시 스키마가 사라졌음을 확인했다.
- pg_dump를 실패시키는 가짜 명령으로 잘못된 백업 파일을 남기지 않는지 확인.
- 공개 URL에서 홈·9월 캘린더·구독 화면·RSS·ICS가 200을 반환하고,
  구독 화면에 공개 도메인이 표시됨을 확인. 재시작 후 collector 정상 실행, 신규 시험 알림 0건.

## 남아 있는 보장 범위

- Web Push 전송과 DB 커밋은 하나의 원자적 작업이 아니다. 푸시 서비스가 수락한 직후
  프로세스가 종료되거나 응답이 유실되면 재시도로 중복 전송될 수 있다.
  이번 변경은 정상 실행 중의 중복과 예외 전파를 줄이며, exactly-once 배송을 보장하지 않는다.
- `SENT`는 푸시 서비스의 수락이다. iPhone 화면에 실제 알림이 표시됐다는 확인은 아니다.
  이번 점검에서 실제 기기로 시험 알림을 추가 발송하지 않았다.
- 수정 이후 새로운 플랫폼·동시 실행 상황에서 발생할 모든 버그가 없다고 단정할 수는 없다.
  현재 활성 실행 경로에서 확인한 문제와 재현 가능한 회귀를 위 범위까지 검증했다.
