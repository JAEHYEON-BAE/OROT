# OROT mobile

Read ../../AGENTS.md, ../../CLAUDE.md and ../../docs/MOBILE_BLUEPRINT.ko.md.
Read the exact installed Expo SDK docs (currently v55.0.0) before changes.

- T-033 uses the public read API through /api/mobile/v1/*. Push remains unimplemented.
- Use Node 22 (.nvmrc), npm ci, and Expo-compatible dependency versions.
- Run npm run check, npx expo install --check and npx expo-doctor.
- iOS/Android folders are generated by prebuild and ignored. Make native changes
  through app.config.ts/config plugins; review before destructive regeneration.
- com.orot.mobile.dev and orot-dev are local development identifiers only.
  Production identifiers and signing are not configured.
- Automated tests use local fixtures. Runtime read verification is separate; never send real notifications without authorization.
- Preserve loopback server ports, Funnel, DB and root environment.
- Record Simulator vs physical iPhone results separately in docs/mobile-validation.

- T-034 theme values live in `theme.ts` at the mobile root; `src/lib/theme.ts` only selects the palette. Use ThemeText and semantic tokens for new UI. See THEME.md for asset/font registration and native rebuild requirements.
